# TinyImageNet results (Experiment 1)

## Contents

| Path | Contents |
|---|---|
| `selfer_paper.csv` | Same-domain results, averaged over A→A and B→B. |
| `transfer_paper.csv` | Cross-domain results, averaged over A→B and B→A. |
| `runs/` | Per-run artifacts, populated by `scripts/tinyimagenet_run.py`. |
| `figures/` | Generated by `scripts/make_figures.py`; git-ignored. |

The two tables are the reference results for this experiment and are canonical
for any reported figure. The pipeline under `src/structured_transfer/tinyimagenet/`
implements the protocol described in the write-up's Appendix A.1; it is
configured independently of these tables, and per-run outputs it produces are
written to `runs/` rather than replacing them.

Both tables use the four-letter backbone notation (`FFTS`), which omits the
always-scratch head. The iWildCam side counts the head explicitly (`F2T1S2`).
`scripts/tinyimagenet_run.py` accepts either form.

Columns: `clean_acc` is the best validation top-1 attained during training,
`corrupt_acc` is top-1 on the TinyImageNet-C-style corrupted validation set, and
the `delta_*` columns are relative to the source-free `SSSS` baseline.

Reporting the best rather than the final epoch matters in this experiment
specifically: the unstable configurations oscillate, so a last-epoch reading
would conflate instability with an unfavourable final sample.

## Reading the tables

The design is a 2×2 of **selfer versus transfer** by **frozen versus
fine-tuned**, and the comparison across it carries the analysis.

- **Selfer** (A→A, B→B): source and target label spaces are identical, so any
  degradation reflects optimization or co-adaptation rather than domain mismatch.
- **Transfer** (A→B, B→A): disjoint 100-class subsets, which additionally exposes
  feature specialization.

The difference between the two isolates specialization from every other effect.

## Principal findings

**Frozen deep features collapse across domains but not within them.** FFFF
attains 73.5% selfer and 53.1% transfer, a 20.4-point gap attributable to the
task-specificity of the deepest residual group (20.6 points measured against the
from-scratch baseline, which is the Δ the table reports). Through Conv1–Group2
the two curves are nearly identical; the divergence appears entirely at Group3.

**Co-adaptation fragility is present but modest.** The selfer frozen curve
declines from 73.7% to 71.8% at FFFS and recovers to 73.5% at FFFF, a swing of
roughly two points and noticeably weaker than the corresponding effect reported
for AlexNet. This attenuation is consistent with WRN-28-10's residual connections
reducing the brittleness of frozen intermediate representations.

**The ternary sweep exposes a failure mode the binary design cannot show.**
Whenever Group2 is fine-tuned while Group3 is trained from scratch — TTTS, FTTS,
FFTS — accuracy falls to 67–69%, independently of the frozen prefix and in both
selfer and transfer runs. That symmetry excludes a domain explanation. Group3
contains 76% of the parameters and is optimized at ten times the learning rate of
the transferred blocks while its input distribution drifts, because the Group2
beneath it is being fine-tuned concurrently. Moving Group3 out of the scratch
state restores near-baseline performance in every case.

This instability has no analogue in the iWildCam experiment, and the difference
is initialization: there, high-performing configurations initialize Stage4 from
ImageNet weights, so the fine-tuned region acts as an adaptation buffer rather
than as a moving boundary into randomly initialized weights. Scratch suffixes are
most hazardous when they are large, high-level, and trained directly above a
fine-tuned block without pretrained initialization.

**Synthetic corruption does not reveal a separate robustness axis.** Corruption
accuracy tracks clean accuracy closely (Pearson r = 0.980 across the 56
source-dependent runs); configurations that fail on clean validation also fail
under corruption. TinyImageNet-C is a synthetic perturbation benchmark, and the
iWildCam experiment remains the relevant test of real distribution shift.

## Running the experiment

```bash
# tiny-imagenet-200 must be present under the data directory
python scripts/tinyimagenet_prepare.py --stage all

# The two source networks, then the transfer runs
python scripts/tinyimagenet_run.py --config SSSS --direction AtoA
python scripts/tinyimagenet_run.py --config SSSS --direction BtoB
python scripts/tinyimagenet_run.py --all        # 58 jobs; see slurm/
```

The semantic A/B class split is derived from WordNet at preparation time, so it
depends on the installed corpus version. `tinyimagenet_prepare.py` reports the
resulting per-group balance and flags any deviation from the split-1 signature
documented in Appendix A.1 (16/17 other-fauna, 9/8 food, even-sized groups halved
exactly). Running it with `--dump-groups` writes `class_groups.csv`, which can be
committed to pin the split across machines and subsequent runs.
